Edge gateway is not running

The Docker nginx gateway did not respond. The whole stack behind /, /app, and /server is unreachable until it comes back.

On the host, start (or restart) the gateway:

pnpm start gateway

Or bring the full local stack up:

pnpm start

Try again

Check container status with docker compose ps gateway and logs with pnpm logs gateway.
